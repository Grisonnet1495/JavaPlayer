# JavaPlayer

JavaPlayer is a music library application built in Java using the vlcj library and following the MVC architecture.
It was developed as part of a second-year Java course at HEPL (Belgium).

This project is still under development, so it may contain bugs.

Please note that this is our first project in Java and our first time using the MVC model, so the app’s usability might not be optimal.
Be aware that you need to have VLC installed to be able to run this application

You are free to compile and modify this project for personal use, as long as you credit the original developers.
